# Gospel Covenant Chibeda — PHP Developer Portfolio

Responsive static portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website content
- `styles.css` — responsive design
- `script.js` — mobile navigation and footer year

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload these three files and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. GitHub will show the published website address in the Pages settings.

## Notes
This is a static portfolio and does not require PHP or a database. Project summaries are portfolio descriptions; WSNAPS source code is not included. The banking project is a demonstration concept only, not a real banking service.
